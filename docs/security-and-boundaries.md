# Security & Public Disclosure Boundary

This repository is a sanitized documentation artifact for proprietary engineering work.

## Never publish

The following categories remain private:

- Private keys or seed phrases
- RPC credentials or API tokens
- Database credentials
- Internal production endpoints
- Sensitive wallet addresses
- Private user or customer data
- Proprietary source code
- Client-confidential infrastructure details

## What this repository demonstrates

The public material focuses on:

- System architecture
- Engineering responsibilities
- State ownership
- Transaction lifecycle reasoning
- Technology choices
- Engineering trade-offs

The goal is to demonstrate engineering capability without exposing confidential implementation details.

## Review Rule

Before adding any new artifact to this repository, verify that it can be understood as a public portfolio document and does not reveal operational secrets or proprietary implementation details.
